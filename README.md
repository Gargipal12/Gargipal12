## 🚀 Featured Projects

### 🤖 [CodePilot AI](https://github.com/Gargipal12/codepilot-ai)
**Multi-Agent AI Software Engineering Assistant**

An AI-powered application that uses specialized agents to support different stages of software development.

- Five specialized agents: Planner, Coder, Reviewer, Tester, and Documentation.
- Human-in-the-loop approval checkpoints and task state management.
- REST APIs for task creation, workflow execution, and approval management.
- Automated testing with pytest.

`Python` `Gemini API` `Multi-Agent Systems` `REST APIs` `pytest`

### 🧠 [VoiceShield AI](https://github.com/Gargipal12/voiceshield-ai-deepfake-detection)
**Explainable Deepfake Voice Detection**

An AI-based system designed to identify synthetic and manipulated audio using deep learning approaches.

- Explored transformer-based audio representations using Wav2Vec2.
- Built CNN-based audio classification using Mel-spectrograms.
- Evaluated models using accuracy, ROC-AUC, and Equal Error Rate (EER).

`Python` `PyTorch` `Hugging Face` `Wav2Vec2` `CNN`

### 🔍 [AI-Based Food Fraud Detection](https://github.com/Gargipal12/ai-food-fraud-detection)
**Image Forensics for Detecting Manipulated Food Images**

An image-analysis pipeline designed to identify potentially manipulated food images, inspired by image-based refund fraud in online food delivery.

- Combined Vision Transformer (ViT), Error Level Analysis (ELA), and handcrafted image features.
- Fine-tuned and evaluated a model on the CIFAKE dataset.
- Achieved **86% accuracy and 0.94 ROC-AUC** in the reported evaluation.

`Python` `PyTorch` `Vision Transformers` `OpenCV` `Image Forensics`

### 💻 [Secure Task Management](https://github.com/Gargipal12/taskmanagement)
**Full-Stack Task Management Web Application**

A task management application with an interactive dashboard and REST API integration.

- Built task creation, updating, deletion, and status-tracking functionality.
- Structured the backend using a layered Controller-Service-Repository architecture.
- Implemented JWT-based authentication and password hashing.
- Created a web interface with task forms, dashboard counters, and task management features.

`Java` `Spring Boot` `Spring Security` `JWT` `JavaScript` `H2` `Docker`

### ⚡ [AI CRM & Sales Automation](https://github.com/Gargipal12/ai-crm-automation-platform)
**AI-Powered Workflow Automation Platform**

An automation project designed to streamline CRM operations and lead management.

- Created five automation workflows using n8n.
- Integrated Gemini API for lead scoring.
- Automated lead assignment based on representative workload.
- Implemented follow-up workflows and activity logging.

`n8n` `Google Gemini API` `Workflow Automation` `Google Sheets`
